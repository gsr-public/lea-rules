# Security Policy

## Reporting a vulnerability

Please report security issues privately by email to **security@gsr-it.com**. Do not open a public issue for a suspected vulnerability.

Relevant issues include, for example:

- a rule whose command could change system state, leak sensitive data, or behave unsafely when run by the LEA agent;
- a remedy that is not safe or not idempotent;
- a regular expression that lets a non-compliant host pass (false negative) in a way that could mislead an assessment.

Please include the rule file path, the operating system and version, sample command output if possible, and the impact you observed.

We aim to acknowledge reports within 3 business days and to agree on a disclosure timeline with you.

Security issues in the LEA Platform itself (server, agent, reports) can be reported to the same address.
